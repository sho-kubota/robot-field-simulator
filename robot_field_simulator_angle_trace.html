ヘルプと手動読込

起動時に同じフォルダの lines.csv と field_bg.jpg(Scan.py が field.pdf から生成)を自動で読み込みます。field_bg.jpg が無い場合はオンラインに限り field.pdf を pdf.js で描画して代用します。Chromeで止まる場合は python3 -m http.server 8000 を実行して http://localhost:8000/ から開いてください。file:// では lines.csv の自動読込のみ制限されます(背景jpgは表示可、PDF代替は無効)。その場合は下の入力かドラッグ&ドロップで読み込めます。画像はHTMLに埋め込まれていません。

操作: ドラッグ=前後移動 / オレンジのハンドルドラッグ=回転 / 空き地クリック=その方向へ前後移動 / Alt+ドラッグ=2点間の距離を測る / 矢印キー=10mm移動・5°回転(Shiftで50mm・15°) / Q・E=±90°回転 / W・S=壁ドン(前進・後退して壁に当て、±45°以内なら直角へ補正。すでに触れている状態で押した場合も、向きが±45°以内ならその場で直角化して密着させます) / 壁への前後移動でも自動で壁ドン(±15°、新たに触れた壁が対象。触れたままの壁ずらしでは補正しない) / ホイール=拡大縮小 / Shift+ドラッグまたは中ボタンドラッグ=表示の平行移動 / R=初期位置・F=全体表示・T=信地/超信地切替 / Ctrl+Z=元に戻す・Ctrl+Y=やり直し。『角度吸着』ON では向きが 0/90/180/270°の±8°以内のとき自動で直角へ吸着し、『黒線吸着』ON では移動先が黒線・交差点から約45mm以内のとき吸着します(各チェックボックスで ON/OFF)。『グリッド』で100mm方眼を表示できます。『信地旋回』ON では片輪を固定して反対輪で弧を描くように回り(回転中に位置が変わり、備考に「信地旋回」と記録)、OFF では超信地旋回でその場回転します(T キーでも切替)。左下の『走行履歴』パネルに、1歩ごとの前後cm・回転°と累計が出ます(readout の『輪L/輪R』は左右タイヤの積算移動量。狭い画面では履歴パネルがフィールドの上に並びます)。軌跡はブラウザに自動保存されます。
